# Clarify Issue

GitHub Issue の内容を確認し、実装前に不明点を洗い出します。実装・コミットはしないでください。

## 手順

1. ユーザーが指定した Issue 番号（なければ確認する）を対象にする
2. GitHub MCP（または `gh issue view`）で `ytr6310zs-jpg/mj-score-manager` の Issue を取得する
3. 次を簡潔にまとめる:
   - 目的の要約
   - 期待挙動（現状と理想）
   - 優先度・期限（記載があれば）
   - CI / 運用上の制約
4. 不明点があれば確認質問を先に提示する（5問程度を目安）

## 制約

- コード変更・コミット・push・PR 作成はしない
- 参照: `docs/issue-prompt-guidelines.md`, `AGENTS.md`
